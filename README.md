# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.


1. Описание проекта:  веб-сервер с REST API для управления задачами.
Планировщик задач позволяет:
- добавлять задачи с датой и комментарием;
- указывать правило повторения (repeat);
- пересчитывать следующую дату выполнения задачи;
- редактировать, удалять и отмечать задачи выполненными;
- получать список задач в формате JSON.

Хранение данных реализовано на базе SQLite. Сервер обслуживает как API-запросы, так и статические файлы фронта.


2. Выполненные задания со звёздочкой
Задания повышенной сложности не выполнялись.

3. Инструкция по запуску локально:

- Версия Go 1.21+
- Поддержка SQLite (используется modernc.org/sqlite)
- Порт 7540 должен быть свободен (или переопределён через TODO_PORT)

4. Инструкция по запуску тестов

- порт должен быть 7540 (или такой же, как в переменной TODO_PORT);
- имя базы по умолчанию — scheduler.db.
- правки в тесты не вносились
- Для запуска всех тестов: go test ./tests
